# Travel Booking & Trip Management System

## Project Description
The Travel Booking & Trip Management System is a web application developed using Python, Streamlit, and MySQL. It helps users explore travel destinations, view tour packages and hotels, search transport options, manage bookings and payments, plan itineraries, and view trip history.

## Technologies Used
- Python
- Streamlit
- MySQL
- SQL

## Project Features
- Dashboard
- Destinations
- Tour Packages
- Hotels
- Transport Search
- Maps
- Book Package
- Payment
- Itinerary
- Cancellation
- Reviews
- Trip History
- My Bookings
- Booking PDF Generation

## Project Files
- `app.py` – Main application interface
- `api.py` – Destination and transport search functions
- `database.py` – MySQL database connection and queries
- `pdf_generator.py` – Generates booking PDF documents
- `travel_booking.sql` – Database tables and sample data
- `requirements.txt` – Required Python packages

## How to Run the Project
1. Install the required packages using `pip install -r requirements.txt`.
2. Create the MySQL database using `travel_booking.sql`.
3. Configure the database connection in `database.py`.
4. Run the application using:

   `streamlit run app.py`

## Conclusion
This project demonstrates how Python, Streamlit, and MySQL can be used to develop a travel booking and trip management application.
